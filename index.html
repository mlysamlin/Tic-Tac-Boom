📱 Jouer sur smartphone

Pourquoi un QR code seul ne peut pas "créer" le site ?
Un appareil photo de smartphone ne peut pas ouvrir de fichier local sur un autre appareil. Il a besoin soit d'une URL web, soit que le fichier soit téléchargé directement sur le téléphone.

Méthode 100% Hors-Ligne (Sans serveur)

Téléchargez le fichier HTML et envoyez-le par AirDrop / WhatsApp / Bluetooth. Il s'ouvrira en local dans Chrome ou Safari sans Internet !
